# Carrd

> Carrd is a hosted no-code builder for simple, fully responsive one-page websites — personal
> profiles, landing pages, portfolios and link pages. Founded by AJ (@ajlkn) and operated by
> Carrd Inc. Carrd publishes NO public API, no developer portal, no SDKs and no machine-readable
> specification. Its only HTTP integration surface points outward: Pro-tier form elements deliver
> submissions into third-party APIs (twenty email/CRM platforms, Zapier, Make, n8n, Airtable) or
> to a URL the site owner supplies. Treat Carrd as an API CONSUMER, not an API provider.

Generated by API Evangelist from apis.yml and the artifacts in this repository. This is a
third-party profile; it is not published by Carrd. Carrd serves no /llms.txt of its own
(https://carrd.co/llms.txt returned 404 on 2026-08-12).

## APIs

Carrd has no public API. Contract discovery on 2026-08-12 probed the first-party host
carrd.co for /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json, /api-docs,
/redoc, /api, /docs/api, /developers, /graphql and every /.well-known/ discovery path —
all returned HTTP 404. No GraphQL endpoint, no MCP server, no A2A agent card.

Caveat for crawlers: *.carrd.co subdomains are member-built sites on the Carrd platform, not
Carrd-operated surfaces. api.carrd.co ("API's Unlimited") and blog.carrd.co ("Official
Carrd.co Blog") both return 200 and are both third-party member pages. Only the apex
carrd.co is first party.

## Plans

- [Go Pro](https://carrd.co/pro): Free tier (3 sites) plus 16 paid annual tiers from Pro Lite
  ($9/yr, 3 sites) to Pro Plus 1000 ($999/yr, 1000 sites), banded Lite / Standard / Plus.
  7-day Pro trial, no card required. No tier includes API access — there is no API.
